# Office app audit — November 17, 2026

Scope: current `main` at `a70776a4a4a5fd714e0a857ffd2334dafdd7a27f`, the existing Render site, all navigation destinations, search, equipment handoffs, airflow tables, charging workflows, printing, and offline saving/update behavior. The hosted page was behind main at the start of the audit.

## Corrections

- Charging comparisons now describe measured subcooling relative to the selected target. A comparison alone no longer issues a direct add/remove instruction or certifies the charge as correct.
- An entered superheat target cannot determine charge for an “Other R-410A / TXV” system. Liquid-side readings and a subcooling target are required.
- R-32 Fit cooling explicitly selects charge verification TEST or FULL-capacity operation; the two installation-manual tables are not evaluated as simultaneous governing targets. The 2-ton below-80°F adjustment applies to TEST only. Unsupported FULL targets stay unavailable.
- DH5SE 5-ton cooling uses the specific low-stage 6 ± 1°F target from IOD-4064A p.11.
- Negative target/tolerance and zero/negative line lengths are rejected. Changing refrigerant, equipment, tonnage, operating mode or TEST/FULL clears readings and typed saturation overrides. Refrigerant switching also clears stale placeholders.
- Unknown-unit factory-charge values are no longer added to known ounces. The factory value and additional line-set ounces remain separate pending nameplate confirmation.
- Measurement plausibility warnings no longer describe heuristic thresholds as manufacturer limits or unusual readings as physically impossible.
- Equipment specifications come only from specification tables, not catalog-comparison or minimum-room-area tables. AMST airflow-only lookup records are registered explicitly.
- DC6VS combined aliases are separate lookup records, with the correct VSA/VSS charge-sheet handoff.
- Airflow handoffs preserve the installed model and select the most specific matching model/manual pattern. Ambiguous source patterns require the exact installed suffix.
- Fit fault references respect the 24–48 versus 60 size split. Shared all-size references remain available.
- Conflicting DX4SQ catalog family/refrigerant metadata is flagged; inferred R-32 manuals and procedures are withheld.
- Submitted model searches cancel pending debounce work so it cannot unexpectedly reset the selected information tab.
- Searching original airflow references hides an unrelated guided result. Missing airflow/watt values have readable labels without misleading numeric units.
- Airflow printing uses legible black text and includes the selected original source table. Equipment printing and hidden AHRI functionality remain covered by regression checks.
- The service-worker cache has a reproducible release fingerprint and a preparation script for future asset changes.

## Manufacturer checks and unresolved source issues

1. **AMST IO-4011B, Table 9 p.13:** downloaded from the manufacturer and visually checked. AMST30CU1300 T9 is 1185/1165/1125/1115/1070/1060/1015/1010/960 CFM. It really repeats T5/T8 in the printed table; the previous “copy error” suspicion was removed. AMST60DU1300 lists T1 and T6–T9 only; T2–T5 remain unavailable.
2. **Fit 3P761829-1B p.31:** TEST and FULL are explicitly separate procedures; checked the model columns and below-80°F TEST note against the downloaded manufacturer PDF.
3. **DH5SE IOD-4064A p.11:** confirmed specific 5-ton low-stage cooling target. The 1.5–4-ton heating table says 8 ± 1°F while running text says 5 ± 1°F. Both remain visible with a warning; this audit does not choose between them. Heating comparisons do not establish charge.
4. **DMVT P1400 / IO-4040B:** saved electric-heat and minimum-CFM tables conflict (DMVT36BP14 3kW 550 vs 630; DMVT60DP14 6kW 1135 vs 1265; DMVT48DP14/60DP14 5kW NR vs 1040/1135). The source card warns against using these combinations as verified settings. Manufacturer retrieval was denied in this environment; no values were guessed or silently replaced.
5. **External links:** 45 unique URLs checked. Two backend.daikincomfort.com PDF routes were blocked by this environment’s proxy (403), so their current browser accessibility is unverified. Two Goodman PDF links open HTML viewers; these are not classified as dead links. URLs remain intact.

The audit checks application behavior and the specific technical sources above. It does not independently re-certify every imported manufacturer specification, wiring diagram, fault definition or system combination. The installed nameplate and applicable manufacturer revision govern. AHRI matchup functionality remains hidden and its original dataset remains preserved.
